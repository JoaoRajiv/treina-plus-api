## Tarefa

Crie os seguintes use cases e agrupe as rotas no prefixo `/me`:

### UpsertUserTrainData

Esse use case deve criar ou atualizar os dados de treino de um usuário.

Parâmetros:

```ts
interface InputDto {
  userId: string;
  weightInGrams: number;
  heightInCentimeters: number;
  age: number;
  bodyFatPercentage: number; // 25 representa 25%
}
```

Resposta:

Ele deve retornar esses mesmos dados.

### GetUserTrainData

Deve retornar os seguintes dados:

```ts
interface OutputDto {
  userId: string;
  userName: string;
  weightInGrams: number;
  heightInCentimeters: number;
  age: number;
  bodyFatPercentage: number; // 25 representa 25%
}
```

Crie as seguintes rotas:

- `GET /me`: chama `GetUserTrainData` e retorna os dados.
- `PUT /me`: chama `UpsertUserTrainData` e cria ou atualiza os dados.

### Regras

- A rota `GET /me` deve retornar `null` (com status 200) caso os dados de treino do usuário ainda não existam, e **não** um erro 404.
- A rota `PUT /me` deve receber os dados no corpo e retornar os dados persistidos com status 200.
- Ambas as rotas devem exigir autenticação.
